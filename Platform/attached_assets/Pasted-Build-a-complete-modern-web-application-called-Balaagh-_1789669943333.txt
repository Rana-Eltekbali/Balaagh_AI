Build a complete modern web application called "Balaagh AI".

Project subtitle:
AI-Powered Crisis Report Analysis and Decision-Support Platform

PROJECT IDEA:
Balaagh AI is a web-based AI decision-support prototype designed to analyze Arabic crisis and emergency reports in the Libyan context.

The user submits an Arabic crisis report, and the system analyzes it and returns structured information:
- Incident Class
- Priority
- Location
- People at Risk
- Required Support
- Relevance
- Short AI-generated Summary

IMPORTANT:
This is a university AI capstone prototype, not a real emergency dispatch system.
Do NOT include emergency calling, real-time emergency dispatch, social media APIs, mobile-app functionality, or crisis prediction.

14. AI MOCK FUNCTION
==================================================

Create a modular function:

analyzeReport(text)

It should return:

{
  incidentClass,
  priority,
  location,
  peopleAtRisk,
  requiredSupport,
  relevance,
  summary
}

Use keyword-based mock logic for the demo.

For example:
If the Arabic report contains words related to fire, return Fire / Explosion.

If it contains flooding/rain/water, return Flood / Severe Weather.

If it contains electricity/water/sewage/fuel, return Infrastructure / Utilities.

If it contains accident/road/traffic, return Road / Transportation.

If it contains injured/trapped/ambulance/rescue, return People at Risk / Medical.

Otherwise return Other.

This is only a temporary demonstration implementation.
